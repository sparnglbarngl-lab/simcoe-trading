Install help

Simcoe Trading isn't signed by Apple or Microsoft yet. That costs money we're putting off until more people use it, so the first time you open it your computer warns you and asks you to confirm. You only do this once: after that it opens normally and installs its own updates.

On a Mac On Windows Updates Your account

On a Mac

You need an Apple Silicon Mac (M1 or later) with macOS 14 Sonoma or later.

  1. Download it. Download for Mac. Safari unzips it for you. In Chrome or Firefox, open your Downloads folder and double-click the zip file.
  2. Move it to Applications. In Finder, drag Simcoe Trading from Downloads into Applications (in Finder's sidebar, or Go › Applications). It needs to be there to update itself.
  3. Open it once. Double-click Simcoe Trading in Applications. Your Mac says "Simcoe Trading" Not Opened because Apple couldn't check it. Click Done, not Move to Trash.
  4. Allow it. Open the Apple menu › System Settings › Privacy & Security. Scroll down to the Security section, which says "Simcoe Trading" was blocked to protect your Mac. Click Open Anyway.
  5. Confirm. Enter your Mac's password (or use Touch ID), then click Open Anyway once more. Simcoe Trading opens.

The Open Anyway button only shows for about an hour after step 3. If it isn't there, do step 3 again. (Right-clicking the app and choosing Open no longer gets past this warning on current macOS.)

On Windows

You need Windows 10 or 11, 64-bit. You don't need an administrator password: it installs for your own Windows account only.

  1. Download it. Download for Windows. If Edge says the file isn't commonly downloaded, click the … beside it › Keep › Show more › Keep anyway. In Chrome, click Keep.
  2. Run the installer. Open the file you downloaded (SimcoeTrading-windows-…-setup.exe). Windows says Windows protected your PC. Click More info, then Run anyway.
  3. Install. Click Next to keep the folder it suggests, tick Create a desktop shortcut if you'd like one and click Next, then Install, then Finish. Simcoe Trading opens, and it's in the Start menu from now on.

To remove it later: Settings › Apps › Installed apps › Simcoe Trading › Uninstall.

Updates

You never need to download it again. About ten seconds after Simcoe Trading opens, it checks for a newer version. If there is one, it downloads it, checks the file is exactly the one we published, and asks:

  • Restart to update: it closes, swaps in the new version and opens again.
  • Later: it updates the next time you open it.

Help › Check for updates… checks straight away. Updates don't bring the warnings above back.

On a Mac, the app can only update itself from the Applications folder. If you opened it from Downloads, it tells you to move it first.

Your account

All of Simcoe Trading works without an account, the analysis included. With one, your watchlists, portfolios, alerts and layouts follow you between computers.

  1. In the app, open File › Account and choose Create an account.
  2. Enter the six-digit code we email you. (Two-step sign-in with an authenticator app is there too, if you want it.)
