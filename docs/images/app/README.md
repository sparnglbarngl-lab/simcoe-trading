# Desktop application screenshots

Captured directly from the local Simcoe Trading Qt application on 2 November 2026.

Each PNG contains the application's page content at 1908 × 1020 pixels, taken from a 1920 × 1200 window at 125%
zoom. The website supplies its own header, navigation and status bar. Every tab has an Amber dark (`-amber`) and
Evergreen light (`-evergreen`) image; the website switches them with the selected theme.

Public feeds populate market data. Portfolio positions and price conditions are examples created in a temporary
app profile. The user's real settings, accounts and positions are never loaded. These are static images.

Regenerate with `tools/capture_app_screenshots.py` using the app's Python environment. See `EDITING.md` for details.
No application source is copied into this website.
